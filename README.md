## Where do you want to start?

| Your goal | What we deliver |
| --- | --- |
| **Launch a SaaS product** | **Rails SaaS Foundation.** We set up authentication, roles, Stripe billing, an admin panel, and automated deployment. From there, we scope the first workflow your customers will pay for. |
| **Get a Rails app moving again** | **Rails Application Rescue Audit.** We review the architecture, dependencies, test coverage, security, and deployment process. You get a prioritized recovery plan you can use with us or your own team. |
| **Add AI to an existing product** | We start with one job your users already do, such as finding an answer in internal documents or extracting fields from incoming files. We agree on what a good result looks like, then integrate and test it against real examples. |

## Work behind the studio

- **Interpreters.travel** began with two connected applications built from scratch. Travelers could search a public directory for interpreters by location, while staff managed the directory through a separate admin backend.
- **Lumiq** brings AI and mathematical models together in software for financial advisors. We contributed to the development of that platform.
- **Repebox** is our own product. Musicians use it to organize lyrics and chords into setlists and project lyrics for everyone singing along. [Explore a live songbook](https://repebox.com/repertories/1)

## How you stay in control

Before we build a feature, you see its scope, acceptance criteria, and price. You decide which features make the release. We build, test, and deploy the approved work, then invoice monthly for completed features. You can change priorities for the next release as you learn from customers.
